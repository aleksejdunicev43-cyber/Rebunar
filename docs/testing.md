# Тестирование Rebunar

## Режим диагностики интерфейса

Режим доступен только на Vite development server и не включается в production-сборке.

Открой приложение с параметром:

`?rebunarTest=1`

Например: `http://localhost:5173/?rebunarTest=1`

Внизу экрана появится индикатор тестирования. В консоли браузера доступен объект `window.__REBUNAR_TEST__`:

- `snapshot()` — текущий маршрут, заголовок экрана, доступные кнопки, события и ошибки;
- `report()` — тот же отчёт в JSON;
- `clear()` — очистить журнал событий.

Журнал фиксирует клики, переходы, JavaScript-ошибки и неуспешные API-запросы. Значения полей, пароли, cookie и тела запросов не сохраняются.

## Браузерные тесты

Тесты запускаются в Chromium через Playwright:

```bash
npm install
npm install --no-save @playwright/test
npx playwright install chromium
npx playwright test
```

GitHub Actions запускает сборку и тесты автоматически при push в основную ветку/тестовую ветку и при pull request в `main`. Отчёт Playwright сохраняется как артефакт `rebunar-playwright-report`.

Сейчас покрыты базовые сценарии входа/переключения на регистрацию, перехода в магазин и добавления ярлыка. Это начальный набор, который будет расширяться по мере появления стабильных тестовых сценариев.

## Ограничения текущего этапа

## Проверка Android APK

Отдельный workflow `rebunar-android-emulator.yml` собирает актуальный frontend, помещает его в Android-проект из ветки `feature/android-bundled-frontend`, собирает тестовый APK с временной CI-подписью и запускает его в виртуальном устройстве Android 15 (API 35). Проверяется установка и запуск приложения; сохраняются снимок экрана, UI hierarchy и logcat в артефакте `rebunar-android-emulator-results`.

Эта проверка пока является smoke-тестом запуска оболочки и загрузки интерфейса, а не полным набором Android UI-тестов. Она не управляет физическим телефоном.
